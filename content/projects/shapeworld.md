background
After visiting Dark Matter in Berlin, I was inspired to create a little light show of my own. I completed this project over the course of a few days, just for fun.

materials
•  One way acrylic mirror
•  Two way acrylic mirror
•  Clear acrylic sheet (for cutting out sides and inner shape)
•  3mm tape
•  LED light strip (2812B, non-waterproof)
•  Circuit building materials (jumper wires, 100uF capacitor, 330 ohm resistor, breadboard, push button)
•  Arduino Nano

process
•  Create design    →    Fusion 360, schematic, Illustrator SVG file
•  Build the frame    →   laser cut acrylic pieces, sand acrylic, adhere sidewalls
•  Program the lights    →   create circuit, program Arduino
•  Put it all together    →   adhere frame to both mirrors
